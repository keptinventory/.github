# Contributing

Thanks for helping.

- **Bugs and ideas:** open an issue in the repository it's about, using a template.
- **Questions:** [Kept's discussions](https://github.com/keptinventory/kept/discussions).
- **Security problems:** never in public. See [SECURITY.md](SECURITY.md).
- **Pull requests:** for anything bigger than a typo, open an issue first so we can agree the
  approach. Keep a pull request to one change, with tests where the repository has them.

Kept itself has its own rules (a CLA and signed-off commits):
[keptinventory/kept › CONTRIBUTING.md](https://github.com/keptinventory/kept/blob/main/CONTRIBUTING.md).

## Labels

Every issue gets one **type** and, once looked at, a **status**; a **priority** and an **area** when it's planned.

| Group | Labels |
|---|---|
| Type | `bug` · `idea` · `documentation` · `question` · `security` · `accessibility` · `dependencies` · `breaking change` |
| Priority | `priority: critical` (data loss, a security hole, Kept down) · `high` (next release) · `medium` (planned) · `low` |
| Status | `status: needs triage` (new) · `needs info` (waiting for the reporter) · `confirmed` · `blocked` |
| Resolution | `duplicate` · `invalid` · `wontfix` |
| Contributors | `good first issue` · `help wanted` |
| Area | per repository: `area: …` |

Everyone here follows the [code of conduct](CODE_OF_CONDUCT.md).
